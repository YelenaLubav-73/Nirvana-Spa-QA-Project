# Nirvana-Spa-QA-Project

## Project Overview
This repository contains QA documentation and test results created for the Nirvana Japanese Spa website as part of a QA Engineer course project.
The project demonstrates practical experience in requirements analysis, manual web testing, UI testing, cross-browser and mobile testing, defect reporting, and requirements traceability.

## My Responsibilities
Analyzed software requirements and identified test conditions
Designed test scenarios and test cases
Performed manual functional testing
Performed UI and visual consistency testing
Performed cross-browser and cross-device testing
Tested responsive behavior on mobile device
Performed localization testing for English, Russian, and Hebrew versions
Identified, documented, and reported defects
Maintained traceability between requirements, test scenarios, test cases, defects, and execution status
